## How to Run

To run the program, follow these steps:

### 1. Configure and activate a python virtual environment (optional)

In a Terminal (Command Prompt or PowerShell), in the project folder, type the following command:

```shell
python -m venv .venv
```

If your shell is Linux or Mac Terminal, in the project folder, type the following command:

```shell
source .venv/bin/activate
```

If your shell is Windows Command Prompt, in the project folder, type the following command:
```shell
.venv\Scripts\activate.bat
```

If your shell is Windows Terminal (or PowerShell), in the project folder, type the following command:

```shell
.\.venv\Scripts\Activate.ps1
```

### 2. Install the dependencies

In a Terminal (Command Prompt or PowerShell), in the project folder, type the following command:

```shell
pip install -r requirements.txt
```

### 3. Run the program

In a Terminal (Command Prompt or PowerShell), in the project folder, type the following command:

```shell
python app
```
