\section{Introdução}

\paragraph{}Séries temporais são coleções de observações realizadas sequencialmente ao longo do tempo, sendo bastante utilizadas em áreas como estatística, matemática aplicada e processamento de sinais \cite{wiki:xxx}. Um dos desafios de se trabalhar com séries temporais consiste na análise da correspondência de duas séries temporais, seja em relação ao alinhamento, ao casamento ou à deformação.\cite{trab}

\paragraph{}Este trabalho tem como objetivo o desenvolvimento de um programa para a análise de séries temporais, através da implementação de algoritmos de análise de padrões de série temporais, seguido do uso dos dados gerados a partir desses algoritmos na classificação das séries através de algoritmos classificadores.

\section{Solução Proposta}

\paragraph{}Para esta solução, foram utilizados os seguintes algoritmos: Dynamic Time Warping (DTW)\cite{sakoe1978dynamic}, Continuous Dynamic Time Warping (CDTW)\cite{munich1999continuous}, Longest Common Subsequence (LCS)\cite{vlachos2002discovering} e Soft Dynamic Time Warping (Soft-DTW)\cite{cuturi2017soft}. Todos eles foram escritos em Pseudo-Código, visando possibilitar a análise da sua complexidade.

\subsection{Dynamic Time Warping}

\paragraph{}Analisando a complexidade do Dynamic Time Warping, é possível perceber que a parte dele que possuí o maior curso são os dois laços ‘para’ aninhados:

\begin{verbatim}
para i de 1 até tamanho(s):
    para j de j_inicio até j_fim:
\end{verbatim}

\paragraph{}Consequentemente a função de complexidade deve ser calculada levando em consideração a quantidade de vezes que esses laços serão executados. Dessa forma é possível perceber que como a variável janela\_busca influencia diretamente na execução do laço mais interno, essa função de complexidade terá como entrada três variáveis: n, que é o tamanho da primeira série temporal; m, que é o tamanho da segunda série temporal; e w, que é o tamanho da janela de busca.

\paragraph{}O laço mais interno do loop será executado min(m, i + w) + 1 - (max(1, i - w)) + 1 vezes. Consequentemente a função de complexidade será $f(n, m, w) = \sum_{i=1}^{n}(min(m, i + w) + 1 - (max(1, i - w)) + 1)$.

\paragraph{}No pior caso, os tamanhos das séries temporais serão iguais (m=n), e a janela de busca será nula. Portanto o algoritmo executará definindo a janela de busca como o máximo entre m e n, que é n, e logo o laço interno executará $min(n, i + n) + 1 - max(1, i - n) + 1$ vezes. Consequentemente a função de complexidade será $f(n, m) = \sum_{i=1}^{n} (min(n, i + n) + 1 - max(1, i - n) + 1)$.

\subsection{Instanciação dos Algoritmos}

\paragraph{}Após criada a classe OneNearestNeighbour, foi necessário instanciar os modelos com os respectivos algoritmos de séries temporais. Para isso, foi criado um dicionário no qual iria armazenar os modelos para cada série temporal e para cada algoritmo de série temporal. \subsection{Treinamento dos Algoritmos}

\paragraph{}Com os modelos instanciados, foi necessário realizar o treinamento dos modelos. Para isso para cada modelo, foi executado o seu respectivo método ‘fit’, que é responsável por realizar o treinamento com as séries temporais de treino. Dessa forma, foi possível o modelo aprender quais padrões de séries temporais são de quais classes.

\subsection{Teste dos Algoritmos}

\paragraph{}Após o treinamento dos modelos, foi necessário realizar os testes dos mesmos. Para isso, foi chamado o método ‘predict’ de cada modelo, passando as séries temporais. Essa foi a parte que mais demandou tempo de processamento, tendo em vista que foi necessário para cada elemento de treino obter a distância dele e compará-la com os modelos de teste, identificando qual classe possuí menor distância. Durante os testes, foram coletados o y predito pelo modelo e armazenado em uma variável.

\subsection{Obtenção das Métricas}

\paragraph{}Com o modelo treinado e testado, foi necessário avaliar a qualidade do modelo. Para isso, foi utilizada a função ‘accuracy\_score’ da biblioteca sklearn. Dessa forma foi calculada a acurácia de cada modelo, possibilitando identificar qual modelo obteve a melhor acurácia. Essas métricas foram salvas em um dicionário indexado pela tupla com o nome da série temporal e o nome do modelo, possibilitando identificar qual modelo saiu melhor para cada série temporal.

\section{Conclusão}

\paragraph{}Infelizmente, devido ao tamanho da entrada de dados, o tempo de execução dos experimentos ultrapassou 1 dia, 19 horas e 40 minutos, no momento em que está sendo escrito este artigo. Como está bem próximo do prazo limite para a entrega do trabalho, não foi possível obter todos os resultados dos experimentos. Porém como a função ‘processar_dataset’ imprime os resultados das acurácias, foi possível copiá-las manualmente para outra planilha jupyter e com isso obter a média da acurácia dos modelos.

\paragraph{}O algoritmo Dynamic Time Warping (DTW) foi o que obteve a maior acurácia: 93,95320227076811\%, já o Soft Dynamic Time Warping (Soft DTW) foi o que obteve a segunda melhor acurácia: 92,75263429517717\%. Já o Derivative Dynamic Time Warping (DDTW) obteve a terceira melhor acurácia: 92,28562733306986\%. E por último o Longest Common Subsequence (LCS) foi o que obteve a pior acurácia: 33,88581709247693\%. Dessa forma foi possível concluir que para a comparação de duas séries temporais, o melhor algoritmo é o Dynamic Time Warping.

\paragraph{}Através deste trabalho, foi possível compreender o funcionamento desses diferentes algoritmos para trabalhar com séries temporais, além de compreender qual desses algoritmos obteve o melhor a melhor solução.
