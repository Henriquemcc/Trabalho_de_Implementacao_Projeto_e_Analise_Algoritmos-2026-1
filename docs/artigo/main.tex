\section{Introdução}

\paragraph{}Séries temporais são coleções de observações realizadas sequencialmente ao longo do tempo, sendo bastante utilizadas em áreas como estatística, matemática aplicada e processamento de sinais \cite{wiki:xxx}. Um dos desafios de se trabalhar com séries temporais consiste na análise da correspondência de duas séries temporais, seja em relação ao alinhamento, ao casamento ou à deformação.\cite{trab}

\paragraph{}Este trabalho tem como objetivo o desenvolvimento de um programa para a análise de séries temporais, através da implementação de algoritmos de análise de padrões de série temporais, seguido do uso dos dados gerados a partir desses algoritmos na classificação das séries através de algoritmos classificadores.

\section{Implementação}

\paragraph{}A construção da interface gráfica foi feita utilizando os recursos providos pela biblioteca Tkinter do Python. Cada uma dessas classes herdam da classe Tkiner.Topleve (exceto a JanelaPrincipal, que herda de Tkinter.Tk).

\paragraph{}No que tange à implementação manual dos algoritmos, ela foi feita nas seguintes classes: ‘DerivativeDynamicTimeWarping’, que implementa o algoritmo Derivative Time Warping; ‘LongestCommonSubsequence’, que implementa o algoritmo Longest Common Subsequence; ‘DynamicTimeWarping’, que implemente o algoritmo Dynamic Time Warping;
‘ContinuousDynamicTimeWarping’, que implementa o algoritmo Continuous Dynamic Time Warping;
e ‘SoftDynamicTimeWarping’, que implementa o algoritmo Soft Dynamic Time Warping. Todas essas classes herdam da classe abstrata ‘WarpingPathAlgorithm’ que exige a implementação do método ‘warping\_paths’, no qual é realizada a execução de cada algoritmo.

\paragraph{}Em relação ao fluxo de execução do programa, ele é controlado pela classe Controlador, que implementa a realização dos principais procedimentos do programa. Para isso foram implementados os seguintes métodos: ‘abrir\_arquivo\_serie\_temporal’, que realiza a abertura de um arquivo de uma série temporal; ‘obter\_algoritmo’ que retorna uma instância de cada algoritmo para os demais métodos do controlador; ‘gerar\_matriz\_alinhamento’ que realiza a geração de uma matriz de alinhamento com base no algoritmo passado por parâmetro; ‘gerar\_matriz\_mapeamento’, que realiza a geração de uma matriz de mapeamento com base no algoritmo passado por parâmetro; ‘executar\_distancia\_dynamic\_time\_warping’, que realiza a execução da Janela da Distância do Dynamic Time Warping; ‘executar\_distancia\_continuous\_dynamic\_time\_warping’, que realiza a execução da Janela da Distância do Continuous Dynamic Time Warping; ‘executar\_distancia\_longest\_common\_subsequence’, que realiza a execução da Janela da Distância do Longest Common Subsequence; ‘executar\_distancia\_derivative\_dynamic\_time\_warping’, que realiza a execução da Janela do Derivative Dynamic Time Warping; e ‘executar\_distancia\_soft\_dynamic\_time\_warping’, que executa a Janela do Soft Dynamic Time Warping.


\section{Relatório de Testes}

\paragraph{}Para o desenvolvimento dos testes com os algoritmos foi criado um notebook jupyter no qual foi importado o dataset do trabalho. Para isso foi utilizado a biblioteca Pandas, á qual foi utilizada para gerar um DataFrame a partir do arquivo CSV da planilha da base de dados, baixado do site oficial. Após o carregamento da planilha no notebook jupyter, foram filtradas as linhas do DataFrame às quais foram sorteadas para o meu trabalho. E dessa forma, foi construído o Data Frame contendo 32 linhas.

\paragraph{}Com o Data Frame carregado e filtrado, foi necessário obter uma lista com os nomes dos datasets. Para isso foi utilizado o atributo ‘iloc’ do Pandas DataFrame ao qual foi filtrado o atributo ‘Name’. Para cada elemento da lista do dataset foi necessário realizar os procedimentos desde a abertura dos arquivos até a obtenção das métricas dos algoritmos. Para isso, foi desenvolvida a função ‘processar\_dataset’ à qual ficou responsável por realizar a abertura dos arquivos do dataset, transformando-os em Pandas Data Frame; formatá-los para um formato que permite treinar os modelos; separar o conjunto de treino do conjunto de testes, criar os modelos dos algoritmos, treinar os modelos, testar os algoritmos, e no final obter as métricas.

\paragraph{}Como os modelos demandam bastante tempo para serem devidamente treinados e testados, a função ‘processar\_dataset’ foi executada de forma paralela para cada série temporal, possibilitando que o processo de treinamento e de teste aproveitassem do paralelismo da máquina à qual foi executado. A implementação do paralelismo se deu a partir do uso do ThreadPoolExecutor da biblioteca nativa do python.
